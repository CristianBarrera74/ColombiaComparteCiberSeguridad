#OWASP ZAP Security Lab
Descripción

Laboratorio enfocado en análisis de seguridad web y detección de vulnerabilidades utilizando OWASP ZAP sobre el dominio latinoamericacomparte.com.

# Objetivos
Analizar tráfico HTTP/HTTPS
Detectar vulnerabilidades web
Evaluar formularios y headers
Identificar configuraciones inseguras
Documentar hallazgos técnicos

# Herramientas Utilizadas
OWASP ZAP
Kali Linux
Navegador Web
Passive Scan
Spider Crawling

# Sitio Analizado
https://latinoamericacomparte.com/

# Vulnerabilidades Evaluadas
Missing Anti-CSRF Tokens
Header Misconfiguration
Information Disclosure
Input Validation
Session Management

# Resultados Obtenidos
Identificación de alertas LOW y MEDIUM

Detección de formularios sin protección Anti-CSRF visible

Análisis de tráfico HTTP/HTTPS

Identificación de headers faltantes

Reconocimiento de recursos y endpoints públicos
