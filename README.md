Burp Suite Security Lab
Descripción

Este laboratorio está enfocado en el análisis de tráfico HTTP/HTTPS y pruebas básicas de seguridad web utilizando Burp Suite sobre la plataforma Latinoamérica Comparte.

El objetivo principal es interceptar, analizar y documentar peticiones realizadas hacia aplicaciones web con fines educativos y de investigación en ciberseguridad.

Objetivos
Interceptar tráfico HTTP y HTTPS
Analizar requests y responses
Evaluar formularios web
Revisar headers y cookies
Identificar endpoints y recursos web
Detectar posibles vulnerabilidades
Documentar hallazgos y evidencias
Realizar análisis de seguridad pasivo
Herramientas Utilizadas
Burp Suite Community Edition
OWASP ZAP
Nmap
HTTrack
Maltego
Kali Linux
Sitio Analizado
https://latinoamericacomparte.com/
Vulnerabilidades Evaluadas
Prompt Injection
Information Disclosure
Header Misconfiguration
Input Validation
Session Management
Policy Evasion
Context Manipulation
Resultados Esperados
Comprensión del funcionamiento del tráfico web
Análisis de comunicación cliente-servidor
Identificación de riesgos de seguridad
Evaluación de respuestas del chatbot
Documentación técnica de pruebas realizadas
Fortalecimiento de conocimientos en pentesting web y seguridad en IA
Framework Utilizado

F-PIA (Framework for Prevention, Identification and Analysis of Prompt Injection)
