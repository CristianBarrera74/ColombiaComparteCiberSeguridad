# Prompt Injection Security Lab
Descripción

Laboratorio enfocado en la evaluación de vulnerabilidades Prompt Injection sobre un chatbot basado en modelos LLM y arquitectura RAG.

El objetivo principal es analizar el comportamiento del sistema frente a instrucciones manipuladas orientadas a alterar respuestas, evadir restricciones y obtener información contextual.

# Objetivos
Evaluar ataques de Prompt Injection
Analizar manipulación de contexto
Identificar fugas de información
Evaluar evasión de políticas
Analizar seguridad en sistemas RAG
Documentar hallazgos técnicos
# Herramientas Utilizadas
Python
Kali Linux
Burp Suite

Modelos LLM
Técnicas Prompt Injection
# Plataforma Analizada
Chatbot basado en LLM

Prompt Injection
