# Information Disclosure Security Lab
Descripción

Laboratorio enfocado en la evaluación de posibles fugas de información sobre un chatbot basado en modelos LLM y arquitectura RAG.

El objetivo principal es identificar si el sistema expone información sensible, contexto interno, prompts ocultos o datos relacionados con la configuración del modelo.

# Objetivos
Detectar posibles fugas de información
Evaluar exposición de prompts internos
Analizar respuestas del chatbot
Identificar debilidades en validación de contexto
Documentar hallazgos técnicos
# Herramientas Utilizadas
Python
Kali Linux
Burp Suite
OWASP ZAP
Modelos LLM
Técnicas OSINT
# Plataforma Analizada
Chatbot basado en LLM
Arquitectura RAG
https://latinoamericacomparte.com/
# Vulnerabilidades Evaluadas
Information Disclosure
Prompt Leakage
Context Exposure
RAG Information Leakage
Input Validation
# Resultados Obtenidos
No se expusieron credenciales sensibles
El sistema bloqueó múltiples solicitudes
Se observaron restricciones conversacionales activas
Algunas pruebas generaron errores internos de procesamiento
Respuestas frecuentes:
