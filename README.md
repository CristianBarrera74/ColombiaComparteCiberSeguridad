# Nmap Security Lab
Descripción

Laboratorio enfocado en reconocimiento de red y análisis de infraestructura utilizando Nmap sobre el dominio latinoamericacomparte.com.

# Objetivos
Identificar puertos abiertos
Detectar servicios activos
Obtener información de la infraestructura
Analizar exposición de servicios públicos
Documentar hallazgos técnicos
# Herramientas Utilizadas
Nmap
Kali Linux
DNS Lookup
Técnicas OSINT
Navegador Web
# Sitio Analizado
https://latinoamericacomparte.com/
# Elementos Analizados
Dirección IP
Puertos TCP
Servicios activos
Servidores web
Servicios de correo
Infraestructura pública
# Resultados Obtenidos
Identificación de servicios HTTP/HTTPS
Detección de servicios SMTP, IMAP y POP3
Enumeración de puertos abiertos
Reconocimiento de tecnologías visibles
Identificación de servicios expuestos públicamente
