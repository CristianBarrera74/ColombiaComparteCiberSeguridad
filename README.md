# Maltego Security Lab
Descripción

Laboratorio enfocado en análisis OSINT y reconocimiento de infraestructura pública utilizando Maltego sobre el dominio latinoamericacomparte.com.

# Objetivos
Obtener registros DNS (MX, NS, SOA y SPF)
Identificar IP, Netblock y ASN
Analizar infraestructura pública
Construir grafos OSINT
Documentar hallazgos técnicos
Herramientas Utilizadas
Maltego Community Edition
DNS Transforms
WHOIS
OSINT
Navegador Web

# Sitio Analizado
https://latinoamericacomparte.com/

# Elementos Analizados
Dominio
Registros DNS
Dirección IP
Netblock
ASN
Infraestructura pública
